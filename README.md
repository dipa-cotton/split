# split
my split keyboard!

## journals
https://stardance.hackclub.com/projects/28331
check out stardance for my journals!

## purpose
i wanted to make a keyboard that tracks biometric data, like heart rate, temperature, and other things using multiple sensors :) it also has a LOT more keys than your average keyboard, and will be a lot more comfortable to use.

## components
the main files are my PCB and Schematic made in kicad, and I have directories of my code as well :)

## BOM
- 100 capacitors
- 100 diodes
- 100 SK6812minis
- 2 XIAO-nRF52840-Plus-SMD
- 2 Olimex_MOD-WIFI-ESP8266-DEV
- 95 SW_Push (cherry mx switches)
- 2 max30102
- 2 tmp102
- 8 FSR
- 2 GSR
- 2 rotary encoders
